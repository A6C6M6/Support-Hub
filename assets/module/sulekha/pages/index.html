സുലേഖ സപ്പോർട്ട് ഹബ്ബ് (SULEKHA)

വാർഷിക പദ്ധതി റിവിഷൻ മാർഗ്ഗനിർദ്ദേശങ്ങളും പതിവ് ചോദ്യങ്ങളും

ഡാഷ്‌ബോർഡിലേക്ക് മടങ്ങുക

പ്രോജക്ട് റിവിഷൻ FAQ സെർച്ച് ചെയ്യുക

സ്പിൽ ഓവർ, ഡി.പി.സി അനുമതി, കോമ്പൻസേഷൻ റിപ്പോർട്ട് തുടങ്ങിയവയെക്കുറിച്ചുള്ള സംശയങ്ങൾ ടൈപ്പ് ചെയ്ത് കണ്ടെത്തുക.

Q1 സ്പിൽ ഓവർ പ്രോജക്ടുകൾ ലഭ്യമാക്കുന്നതിന് Completion Report നടപടികൾ എന്തൊക്കെയാണ്?

നിർവഹണ ഉദ്യോഗസ്ഥർ അവരുടെ ലോഗിനിൽ Projects → Completion Report മെനുവിലൂടെ താഴെ പറയുന്നവ ചെയ്യേണ്ടതാണ്:

  • പൂർത്തീകരിച്ച പ്രോജക്ടുകൾ തുറന്ന് Completion Date രേഖപ്പെടുത്തി Save ചെയ്യുക.
  • പൂർത്തീകരിക്കാത്ത പ്രോജക്ടുകളിൽ പൂർത്തീകരണ തീയതി രേഖപ്പെടുത്താതെ Save ചെയ്യുക (ഇവ മാത്രമാണ് Spill Over ആയി ലഭിക്കുക).
  • എല്ലാ പ്രോജക്ടുകളുടെയും റിപ്പോർട്ടുകൾ നൽകിയ ശേഷം Report to LB ക്ലിക്ക് ചെയ്ത് തദ്ദേശഭരണ സ്ഥാപനത്തിലേക്ക് സമർപ്പിക്കുക.
ശ്രദ്ധിക്കുക: ഒരു ഉദ്യോഗസ്ഥന് 10 പദ്ധതികൾ ഉണ്ടെങ്കിൽ, 10 പ്രോജക്ടുകൾക്കും റിപ്പോർട്ട് നൽകണം. ഒന്നിൽ പോലും ബാക്കിയുണ്ടായാൽ Spill Over Transfer ഓപ്ഷൻ ലഭ്യമാകില്ല.
Q2 Completion Report പൂർത്തിയാക്കിയാൽ മാത്രമേ Project Transfer ചെയ്യാൻ സാധിക്കുമോ?

അതെ. Completion/Non Completion Report എൻട്രിയും Secretary Forward നടപടിയും പൂർത്തിയായ ശേഷം മാത്രമാണ് അടുത്ത പദ്ധതി വർഷത്തിലേക്ക് പ്രോജക്ട് Transfer ചെയ്യാൻ സാധിക്കുക.

Q5 Project Transfer ചെയ്യുമ്പോൾ ലഭിക്കുന്ന മൂന്ന് ഓപ്ഷനുകൾ എന്തൊക്കെയാണ്?
  • (A) No Change: പദ്ധതിയിൽ മാറ്റമൊന്നുമില്ലെങ്കിൽ ഉപയോഗിക്കുക. മുൻവർഷത്തെ വിവരങ്ങൾ അതേപടി തുടരും.
  • (B) Need Change: സർക്കാർ മാനദണ്ഡങ്ങൾക്കനുസരിച്ച് ഭേദഗതികൾ വരുത്തേണ്ട സാഹചര്യത്തിൽ ഇത് തിരഞ്ഞെടുക്കുക.
  • (C) To Be Dropped: ഇനി നടപ്പിലാക്കാൻ കഴിയാത്ത പദ്ധതികൾ പൂർണ്ണമായും ഒഴിവാക്കാൻ ഉപയോഗിക്കുക.
മുന്നറിയിപ്പ്: To Be Dropped തിരഞ്ഞെടുത്ത് Save ചെയ്താൽ പിന്നീട് ആ പ്രോജക്ട് തിരിച്ചെടുക്കാനോ Spill Over ചെയ്യാനോ സാധിക്കില്ല.
Q12 സുലേഖയിൽ Revision Enable ആകുന്നതിനുള്ള പ്രാഥമിക നിബന്ധന എന്താണ്?

വാർഷിക പദ്ധതി സമർപ്പിച്ചതിന് ശേഷം, ജില്ലാ ആസൂത്രണ സമിതിയുടെ (DPC) അംഗീകാരം ലഭിച്ച് Proceedings Generate ചെയ്ത് Process Completed ആകണം. അതിന് ശേഷം സെക്രട്ടറിയുടെ ലോഗിനിൽ നിന്ന് Enable Revision Request സമർപ്പിച്ച് DPC അത് അംഗീകരിക്കണം.

Q15 Project Revision / Drop / New Project ഉൾപ്പെടുത്തുന്നതിനുള്ള അപേക്ഷ DPC-യ്ക്ക് എങ്ങനെ സമർപ്പിക്കാം?
  1. Secretary Login → Revision → Approved List വഴി പ്രവേശിക്കുക.
  2. DPC അനുമതി ലഭിച്ച ശേഷം Mark for Revision / Drop തിരഞ്ഞെടുക്കുക.
  3. Remarks രേഖപ്പെടുത്തി Forward to DPC സമർപ്പിക്കുക.
  4. പുതിയ പ്രോജക്ടിന് Add New Project ഉപയോഗിക്കുക (മലയാളത്തിൽ പേര് ചേർത്താൽ പിന്നീട് മാറ്റാൻ കഴിയില്ല).
Q24 കണ്ടിജൻസി (Contingency) ഫണ്ട് വകയിരുത്തൽ പരിധികൾ എന്തൊക്കെയാണ്?

ദുരന്തങ്ങൾ, അടിയന്തിര മെയിന്റനൻസ് തുടങ്ങിയ പ്രവൃത്തികൾക്ക് DPC യുടെ മുൻകൂർ അനുമതിയില്ലാതെ തുക വകയിരുത്താം:

  • തനത് ഫണ്ട് (Own Fund): ബാക്കി വരുന്ന തനത് ഫണ്ടിന്റെ പരമാവധി 25% വരെ.
  • മെയിന്റനൻസ് നോൺ-റോഡ് (Non-Road): ഗ്രാമ/ബ്ലോക്ക്/മുനിസിപ്പാലിറ്റി - പരമാവധി ₹25 ലക്ഷം, കോർപ്പറേഷൻ - ₹40 ലക്ഷം, ജില്ലാ പഞ്ചായത്ത് - ₹50 ലക്ഷം.
  • മെയിന്റനൻസ് റോഡ് (Road): ഗ്രാമപഞ്ചായത്ത് - ₹10 ലക്ഷം, മറ്റുള്ളവ - ₹25 ലക്ഷം, കോർപ്പറേഷൻ - ₹50 ലക്ഷം.
Q31 Joint Venture (സംയുക്ത) പദ്ധതികൾ തയ്യാറാക്കുമ്പോൾ ശ്രദ്ധിക്കേണ്ട കാര്യങ്ങൾ

1. ഫണ്ട് സ്വീകരിക്കുന്ന (Implementing) Local Body: Sl. No. 19 Project Implementation ശൂന്യമായി ഇടണം. Sl. No. 30 Source of Funds നൽകണം.

2. ഫണ്ട് നൽകുന്ന (Fund Transfer) Local Body: Sl. No. 19 ൽ ഫണ്ട് സ്വീകരിക്കുന്ന Local Body യുടെ Code നിർബന്ധമായും ചേർക്കണം.

Q32 പ്രോജക്ട് ഡാറ്റാ എൻട്രി സമയത്തെ Category 50 തിരഞ്ഞെടുക്കൽ
  • 50(1): നൂതന (Innovative) / DLEC പരിശോധന ആവശ്യമായ പ്രോജക്ട്.
  • 50(2): നിർവഹണ ഉദ്യോഗസ്ഥന്റെ Certificate മാത്രം മതിയായവ.
  • 50(3): നിർവഹണ ഉദ്യോഗസ്ഥന്റെ മേലുദ്യോഗസ്ഥന്റെ അംഗീകാരം ആവശ്യമായവ.
  • 50(4): മേലുദ്യോഗസ്ഥന്റെ അംഗീകാരവും Technical Sanction (സാങ്കേതിക അനുമതി) യും ആവശ്യമായ നിർമ്മാണ പ്രവൃത്തികൾ.
