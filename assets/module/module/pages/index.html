Getting Started

  1. Open MODULE TEMPLATE from the Support Hub module directory using your staff login.
  2. Select the correct local body / office and financial year where applicable.
  3. Use the module's own menu to reach the screen you need.
  4. Save or submit each entry before navigating away.
  5. Contact your module administrator if a screen differs from this guide.
