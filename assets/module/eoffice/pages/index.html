Getting Started

  1. Open E-OFFICE from the Support Hub module directory using your staff login.
  2. Select the correct local body / office and financial year where applicable.
  3. Use the module's own menu to reach the screen you need.
  4. Save or submit each entry before navigating away.
  5. Contact your module administrator if a screen differs from this guide.

Frequently Asked Questions

Q1. How do I access E-OFFICE?

Open E-OFFICE from the Support Hub module directory. You will need valid staff credentials for the underlying system before you can log in.

Q2. Who do I contact if E-OFFICE is not working?

Raise a ticket through Contact Support with a description of the issue, the page you were on, and a screenshot of any error message.

Q3. Where can I find E-OFFICE documentation?

Reference documents for this module are listed under the Documentation section below and are managed by the Support Hub administrator.
